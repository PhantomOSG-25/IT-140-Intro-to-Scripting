# IT 140 — Python Scripting Foundations

This portfolio turns verified IT 140 design evidence into a small, testable Python example. It focuses on problem decomposition, list and dictionary processing, input validation, and deterministic output.

## What this demonstrates

- Parsing and validating simple text records
- Sorting records with a clear, deterministic key
- Counting words with case normalization
- Separating reusable functions from the command-line entry point
- Writing focused tests for normal and boundary behavior

The text-adventure storyboard, pseudocode, and flowchart remain private supporting evidence. The Python implementation in `src/` is a clearly labeled portfolio extension based on those verified designs, not a claim that recovered original source code was found.

## Run

```powershell
python -m pytest
python -m src.scripting_portfolio
```
